Mind Maps

Import PowerPoint files (.pptx) and each deck becomes a map you can edit. With an API key in Settings, Claude organizes the deck the way you ask. Select several files at once. Saved map files (.json) load back in the same way.

To install: tap the Share button in Safari, then Add to Home Screen. The app then opens full screen and works offline. Maps are stored on this device, so use Export on a card to keep a backup.
Tap to select · double-tap to rename · pinch to zoom
